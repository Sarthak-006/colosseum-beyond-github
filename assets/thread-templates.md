# Thread templates

## Thread type 1 — "Why now" (visionary)

1. **Tweet 1:** Contrarian observation about the category.
2. **Tweet 2:** What changed technically or socially (1 reason).
3. **Tweet 3:** What you built (plain).
4. **Tweet 4:** Demo or diagram.
5. **Tweet 5:** Who it is for + CTA.

## Thread type 2 — "How it works" (technical)

1. **Tweet 1:** Promise + scope ("by the end you'll understand X").
2. **Tweet 2:** User flow in 1 diagram or bullet list.
3. **Tweet 3:** Core mechanism (contracts, APIs, trust assumptions).
4. **Tweet 4:** Threat model or limits (builds trust).
5. **Tweet 5:** Repo/docs link + how to contribute or try.

## Thread type 3 — "Receipts" (credibility)

1. **Tweet 1:** Claim you can back.
2. **Tweet 2–4:** Evidence (latency numbers, cost, user quote)—**honest** ranges only.
3. **Tweet 5:** What you are measuring next.

## Thread type 4 — "Compare / contrast"

1. **Tweet 1:** Old approach vs new approach table image or bullets.
2. **Tweet 2:** When old approach still valid (nuance).
3. **Tweet 3:** Link + CTA.
