# Demo script / shot list (60–90 seconds)

## Structure

| Sec | Beat | On screen |
| --- | ---- | --------- |
| 0–5 | Hook | User pain text or spoken |
| 5–20 | Before / after | Old flow vs your flow |
| 20–50 | Core demo | Happy path only |
| 50–70 | "Why Solana" | 1 line + proof if visual |
| 70–90 | CTA | Link + what feedback you want |

## Voiceover prompts

- "You know how {PAIN}? We {SOLUTION_NOUN} so {AUDIENCE} can {OUTCOME}."
- "Here's the entire flow in one take—no cuts for the tricky part: {STEP}."

## B-roll ideas

- Terminal or logs **only** if dev audience; otherwise UI.
- Face cam optional; increases trust for consumer products.

## Do not

- Read the README aloud.
- Show seed phrases or private keys (ever).
