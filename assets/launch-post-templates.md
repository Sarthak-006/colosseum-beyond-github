# Launch post templates

Replace `{HOOK}`, `{PROOF}`, `{CTA}`; keep under ~240 chars per tweet where possible for QT room.

## Template A — Outcome first

```
{HOOK: specific user outcome in plain language}

{PROOF: demo link / video / screenshot thread index}

{CTA: one ask—try, follow build, or reply with feedback}

Built for {AUDIENCE} on @solana — {ONE_TECH_DIFFERENTIATOR}.
```

## Template B — Problem interrupt

```
People still {OLD_BEHAVIOR}.

We {NEW_BEHAVIOR} by {MECHANISM_IN_6_WORDS}.

{LINK}

Why on Solana? {ONE_TRUE_REASON}.
```

## Template C — Build log

```
Day {N} of {HACKATHON_NAME}: shipped {CONCRETE_THING}.

What broke: {HONEST_LINE}

What we learned: {INSIGHT}

{LINK_OR_SCREENSHOT}
```

## Template D — Ecosystem attach (use sparingly)

```
Everyone's talking about {NARRATIVE}.

Here's what that actually looks like in software: {YOUR_ANGLE}

{LINK}
```

## Template E — Founder voice

```
I'm {NAME/ROLE}. I got tired of {PAIN}.

So we built {PROJECT}: {ONE_LINE}.

If you {AUDIENCE_ACTION}, this is for you.

{LINK}
```
