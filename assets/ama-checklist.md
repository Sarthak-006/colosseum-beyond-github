# AMA / X Space checklist

## Before

- [ ] One-line **why care** memorized.
- [ ] Demo path rehearsed (slow network fallback: screen recording).
- [ ] **3 stories**: founding pain, hardest technical surprise, honest limitation.
- [ ] Links: demo, GitHub/docs, feedback form or Discord if any.
- [ ] Pinned post or profile line updated within 24h of Space.

## During

- [ ] Repeat project name + one-liner **once every ~10–15 min** for late joiners.
- [ ] Answer **security / trust** questions directly.
- [ ] Credit teammates and inspirations (ecosystem goodwill).

## After

- [ ] Thank hosts / co-speakers publicly.
- [ ] Post **1–3 clips** with captions.
- [ ] Thread with **FAQ** if same questions repeated.

## Getting invited (tactics)

- Offer **exclusive mini-demo** or data relevant to the host's audience.
- Write a **QT recap** of their last Space with substance (not promo).
- Ship visible progress so DMs are not cold.
