# X content formats — picker

Match **2 primary** and **1 secondary** format for the first 30 days unless the team has capacity for more.

| Format | When it works | Risk |
| ------ | -------------- | ---- |
| Short hook + demo clip | Most tools and apps | Needs tight editing |
| Technical thread | Infra, security, novel mechanism | Can be dry if no "why care" |
| Build log | Long hackathon, relatable arc | Can feel noisy if no substance |
| Quote-tweet lesson | News-driven cycles | Needs fast judgment |
| Meme / one-liner | Consumer, strong voice | Trust damage if misfit |
| Architecture diagram | Complex systems | Use **after** emotional hook exists |
| Metrics post | Once numbers are honest | Credibility hit if vanity |
| AMA / Space clip | Credibility + network | Prep time |

## Week mapping (default template)

| Week | Goal | Favored formats |
| ---- | ---- | ---------------- |
| 1 | Discovery | Clip, short launch post, pinned refresh |
| 2 | Credibility | Thread, diagram, user flow |
| 3 | Ecosystem | QT, replies, collab posts, Space |
| 4 | Momentum | Metrics, roadmap, retrospective |

## "Why should crypto Twitter care?" per format

Each post type should answer the question **in the first line** or **first second of video**.
