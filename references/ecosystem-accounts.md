# Ecosystem insertion map

**Do not treat as a static @ list**—accounts and narratives shift weekly. Use **categories**; the agent finds **current** high-signal accounts via search and recent posts.

## Narrative lanes (pick 1–2 primary)

| Lane | Where to show up |
| ---- | ----------------- |
| AI × Solana / agents | Threads on tooling, evals, safety, wallets + agents |
| Consumer crypto UX | Mobile, payments, onboarding, abstracting chain |
| Infra / reliability | RPC, indexing, devex, performance, MEV-adjacent tooling |
| DeFi composability | Risk, liquidity, new primitives, analytics |
| DePIN / RW coordination | Hardware, supply chain, proofs, maps |
| Gaming / meta | Distribution, UGC, economies |
| Creator economy | minting, royalties, audience ownership |

## Types of accounts to engage (archetypes)

- **Protocol / infra founders** — technical QTs with reproducible results.
- **Developer advocates** — tutorials that use their stack honestly.
- **Research / analytics** — charts, comparisons, limitations disclosed.
- **Media / podcasts** — when you have a **story** and demo, not a cold pitch.
- **Regional / guild communities** — Superteam-style collectives where applicable (search current chapters).

## How to earn replies

- Bring **new information** (benchmark, design tradeoff, user quote).
- **Ack limits** early for trust (security, centralization phases, testnet vs mainnet).

## Pitfalls

- Spray-tagging **Solana** or **Colosseum** accounts on every post.
- Threading solely in English when the team's edge is a **specific** geography (use Arena country filter to find peers).
