# Colosseum Arena: how to mine comparables

## Canonical URLs

- **Explore projects (filters):** https://arena.colosseum.org/projects/explore  
  Use: **Category**, **Hackathon Track** (legacy tracks), **Country**, **Show only winners and honorable mentions**.
- **Hall of Fame:** https://arena.colosseum.org/hackathon/hall-of-fame  
  Use for **grand prize lineage** and repeated winners (persistence signal).
- **Hackathon hub / cycles:** https://colosseum.com/hackathon  
- **Arena hackathon landing:** https://arena.colosseum.org/hackathon  

## How to select comparables

1. Match **track + category** when possible; if sparse, widen category before dropping quality filter.
2. Prefer projects with: **clear one-liner**, **demo or video**, **visible updates**, **GitHub or docs** linked from Arena.
3. Record **3 bullets per project**: positioning, format emphasis, ecosystem hook.

## Names often cited on Colosseum properties (examples to study, not templates to copy)

Hall of Fame and marketing pages have highlighted projects such as **Unruggable**, **TAPEDRIVE**, **Reflect Protocol**, and **Ore** as grand prize stories—use Arena profiles + X search **as-of the session** to extract **current** bios, cadence, and pinned patterns. Do not invent historical posting statistics.

## Blog and announcements

Search `site:blog.colosseum.com` + hackathon name for **winner posts** and track narratives. Use for **official framing** judges and sponsors responded to.

## Integrity rules for the agent

- Cite **patterns**, not fabricated metrics.
- If X search is unavailable, say so and lean on **Arena copy + README positioning** from links the user provides.
